# **App Name**: Order Aggregator

## Core Features:

- Account Linking: Allow users to link their online shopping accounts by providing credentials.
- Order Fetching: Automatically fetch order history from linked accounts, with consideration given by an LLM tool to filtering duplicate order entries.
- Unified View: Present a consolidated view of all orders from various platforms in a single list.
- Order Filtering & Sorting: Enable users to filter orders by date, status, and platform, and sort them by date and status.
- Order Details: Display detailed information for each order, including items, price, and shipping address.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to convey trust and organization.
- Background color: Very light blue (#E3F2FD) for a clean, unobtrusive background.
- Accent color: Light orange (#FFB74D) to highlight important actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif font, providing a modern and neutral feel suitable for both headlines and body text.
- Use clear and simple icons for platforms, order statuses, and filters.
- Clean, card-based layout to display orders, making it easy to scan and digest information.
- Subtle transitions and loading animations to provide feedback and enhance the user experience.
